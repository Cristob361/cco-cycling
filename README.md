# CCO Cycling - Landing Page Project

This repository contains the source code for the CCO Cycling landing page, a fictional premium bicycle boutique.

## Project Overview

This project is an academic exploration demonstrating the integration of a conversational AI assistant (CycloBot, powered by Chatbase) into a digital commerce experience. The goal is to showcase how AI can enhance customer engagement and provide personalized guidance.

The website features:
*   A responsive design suitable for various screen sizes.
*   A visually distinct "galactic" theme with dark backgrounds and neon cyan highlights.
*   Sections for Hero (with Call to Action), Bikes, Services, About, and Footer.
*   A floating chat icon that toggles an embedded AI assistant (CycloBot) to help users find bikes.

## Technologies Used

*   **HTML5:** For structuring the web page content.
*   **CSS3:** For styling the page, including the galactic theme, responsiveness, and animations. Google Fonts (Orbitron, Montserrat) are used for typography.
*   **Vanilla JavaScript:** For interactive elements, specifically toggling the chatbot modal.
*   **Chatbase:** (External service) Used for the embedded AI chatbot functionality.

## How to View

1.  **Locally:** Clone this repository and open the `index.html` file in your web browser.
2.  **GitHub Pages:** If deployed, you can access the live site via the GitHub Pages URL for this repository.
